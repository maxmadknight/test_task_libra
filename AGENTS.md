# Repository Instructions

## Memory Bank

At the start of every task, read all Markdown files in `docs/memory-bank/` before making changes. Treat Memory Bank as the primary source of durable project context.

Keep broad project scope, architecture notes, current status, and durable decisions in `docs/memory-bank/`. Keep this file focused on operating rules for agents.

Use the Memory Bank Manager workflow when initializing, updating, auditing, or reconciling `docs/memory-bank/`.
